# Security Policy

## Repository Scope

This repository contains **showcase and documentation content only**. It does not contain:

- Production credentials, API keys, or tokens
- Wallet seed phrases or private keys
- Internal deployment configurations
- Database connection strings
- Customer or client data
- Private server URLs or infrastructure details

All sensitive configuration is managed via environment variables in private, secured infrastructure and is never committed to any public repository.

## Supported Versions

This showcase repository does not contain production software. For security enquiries related to SYNAPZ AI Ltd production systems, see below.

## Responsible Disclosure

If you discover a security vulnerability in any SYNAPZ AI Ltd system or believe sensitive information has been inadvertently exposed in this or any related repository, please contact us **privately** before disclosing publicly.

**Security contact:** [murat@synapzgroup.net](mailto:murat@synapzgroup.net)

Please include:
- Description of the issue
- Steps to reproduce or evidence
- Any relevant repository URLs or file paths

We will acknowledge receipt within 48 hours and aim to respond substantively within 7 days.

**Please do not open public GitHub issues for security vulnerabilities.**
